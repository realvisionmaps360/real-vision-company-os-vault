# Estudos — The Secret Teachings of All Ages (Manly P. Hall)

> Projeto pessoal do Felipe. Sem relação com o projeto do jogo (Jogo da Terra / earth-game) — é só o estudo do livro em si, capítulo por capítulo, pra entender o conteúdo de verdade.

## O que é esse projeto

Ler *The Secret Teachings of All Ages* (Manly P. Hall, 1928, domínio público) inteiro, capítulo por capítulo, e reescrever cada capítulo em português simples — sem cortar conteúdo, só traduzindo a linguagem difícil e explicando os termos técnicos/místicos na hora que aparecem.

## Método (repetir para cada capítulo novo)

1. **Localizar o capítulo** na edição em inglês do sacred-texts.com (`sacred-texts.com/eso/sta/`). O índice completo com os 46 capítulos, número de página e link de referência já está mapeado em [`operacao/projetos/_RV-Internos/jogo-da-terra/docs/LIVRO-BASE.md`](../../operacao/projetos/_RV-Internos/jogo-da-terra/docs/LIVRO-BASE.md) — seção 2 (índice) — mesmo esse projeto sendo do jogo, o índice serve pra qualquer uso.
2. **Extrair o texto completo do capítulo** (WebFetch direto no sacred-texts.com costuma dar 403 — usar o Firecrawl scrape como alternativa).
3. **Reescrever o capítulo inteiro** em português, mantendo:
   - Todo o conteúdo original (nenhuma ideia cortada, resumo raso não vale)
   - Linguagem simples e lúdica, como se estivesse explicando pra alguém curioso mas sem repertório místico/filosófico prévio
   - Cada termo difícil (grego, latim, jargão esotérico) explicado na hora que aparece, não só num glossário no fim
   - Ainda assim, incluir um **glossário rápido no final** pra consulta
4. **Salvar como arquivo novo** nesta pasta, nomeado `cap-XX-titulo-curto.md` (número do capítulo conforme a edição original de 1928).
5. **Atualizar a tabela abaixo** com o novo capítulo.

## Regras deste projeto

- Fonte é sempre o texto integral do capítulo — nunca resumir a partir de resumos de terceiros.
- Fidelidade ao conteúdo original vem antes da fluidez — se um trecho for ambíguo no original, isso deve aparecer no texto simplificado também, sem inventar clareza que a fonte não tem.
- Sem relação com o Jogo da Terra — não misturar conteúdo de gameplay aqui; se algo deste estudo for útil pro jogo depois, isso é decidido separadamente.
