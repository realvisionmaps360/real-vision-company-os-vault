# 09 — Arquivo

Encerrados. **Nada é apagado, só aposentado.**

## Regra

Ao arquivar: `status: arquivado`, e o motivo vai como última linha do `## Histórico`. As arestas permanecem — um projeto arquivado continua ligado às decisões que ele gerou, e é assim que a memória do sistema sobrevive.

Isso vem de duas fontes que dizem a mesma coisa: o §9 da spec e a regra de ouro nº6 do [[AGENTS]] ("nunca apague notas, só crie").
