# 01 — Objetivos

Guarda **apenas objetivos**. Nunca tarefas.

A diferença: objetivo é um estado do mundo que você quer que seja verdade. Tarefa é uma ação. "Casar na Suíça" é objetivo; "traduzir a certidão" é tarefa. Tarefas moram em `07-Operacao/` e nos projetos.

## Horizontes

`anual` · `trimestral` · `mensal` · `financeiro` · `pessoal`

## Regra

Todo objetivo precisa de um critério verificável em `## Como se mede`. Se não dá pra medir, não é objetivo — é desejo, e desejo mora em `05-Conhecimento/`.
