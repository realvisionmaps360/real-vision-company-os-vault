# 07 — Operação

O que muda todo dia. E, mais importante: **a porta de entrada do sistema**.

## `inbox/` — onde tudo começa

> Nenhuma informação entra solta (§10).

Ideia, recado, número, foto de nota fiscal, decisão tomada no almoço — tudo cai aqui primeiro, cru, com data. Depois passa pelo fluxo de sete passos e vira nó no lugar certo.

Jogar no inbox é barato de propósito. Se registrar custar esforço, você não registra, e o sistema morre de fome.

## O fluxo (§29)

```
inbox → classificar → identificar entidades → mapear relações
      → analisar impacto → atualizar o que muda → registrar
```

**O passo de impacto nunca é pulado**, e o resultado é sempre mostrado antes de qualquer atualização. O sistema recomenda; o Felipe decide (§36).
